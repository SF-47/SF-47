### 🔎 Findly — Smart Lost & Found Platform

AI-assisted lost-and-found platform designed for university campuses.

<p>
  <img src="https://img.shields.io/badge/ASP.NET_Core-512BD4?style=flat-square&logo=dotnet&logoColor=white" alt="ASP.NET Core" />
  <img src="https://img.shields.io/badge/React-149ECA?style=flat-square&logo=react&logoColor=white" alt="React" />
  <img src="https://img.shields.io/badge/React_Native-20232A?style=flat-square&logo=react&logoColor=61DAFB" alt="React Native" />
  <img src="https://img.shields.io/badge/PostgreSQL-336791?style=flat-square&logo=postgresql&logoColor=white" alt="PostgreSQL" />
  <img src="https://img.shields.io/badge/Supabase-3ECF8E?style=flat-square&logo=supabase&logoColor=white" alt="Supabase" />
  <img src="https://img.shields.io/badge/n8n-EA4B71?style=flat-square&logo=n8n&logoColor=white" alt="n8n" />
  <img src="https://img.shields.io/badge/Gemini_AI-4285F4?style=flat-square&logo=google&logoColor=white" alt="Gemini AI" />
</p>

- Developed a full-stack platform with an ASP.NET Core backend, React admin dashboard, and React Native mobile application.
- Implemented JWT authentication and role-based authorization for Owner, University Admin, and Student users.
- Integrated n8n and Gemini AI to evaluate lost and found reports and generate matches with confidence levels and reasoning summaries.
- Improved matching accuracy using university filtering, category matching, date-window checks, and duplicate-prevention logic.
- Built workflows for student verification, lost and found reporting, match review, notifications, and match-based chat.
- Used PostgreSQL and Supabase for structured data storage and application database management.

**Repository:** [View Findly on GitHub](https://github.com/SF-47/findly)  
**Demo Video:** [Watch the Findly Demo](https://drive.google.com/file/d/1v0SOa4yqmMoDwy0Iu_RnM6rnAb1L9V1M/view?usp=sharing)

### 🌯 Shawarma Story QR Menu

A production-ready QR restaurant menu built for a real business.

<p>
  <img src="https://img.shields.io/badge/React-149ECA?style=flat-square&logo=react&logoColor=white" alt="React" />
  <img src="https://img.shields.io/badge/Vite-646CFF?style=flat-square&logo=vite&logoColor=white" alt="Vite" />
  <img src="https://img.shields.io/badge/Tailwind_CSS-38BDF8?style=flat-square&logo=tailwindcss&logoColor=white" alt="Tailwind CSS" />
  <img src="https://img.shields.io/badge/Firebase-FFCA28?style=flat-square&logo=firebase&logoColor=111827" alt="Firebase" />
  <img src="https://img.shields.io/badge/Cloudflare-F38020?style=flat-square&logo=cloudflare&logoColor=white" alt="Cloudflare" />
</p>

- Built a responsive, mobile-first QR menu optimized for customers scanning from their phones.
- Implemented bilingual English and Arabic support with RTL layout handling and localized menu content.
- Added a cart system with quantity controls, customer notes, and formatted WhatsApp checkout messages.
- Built a protected admin panel using Firebase Authentication and Firestore.
- Enabled administrators to add, edit, delete, categorize, price, and control the availability of menu items.
- Deployed the application using Firebase Hosting and connected a custom Cloudflare-managed domain.
